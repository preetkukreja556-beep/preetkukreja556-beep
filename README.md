## 👨‍💻 About Me

I'm an AI & ML student who fell in love with the part of software that happens *after* the code is written: building, testing, securing, shipping and running it reliably.

I learn by building. My projects focus on **end-to-end delivery pipelines**: containerizing apps, automating builds with CI/CD, scanning for security issues early (DevSecOps), and deploying through GitOps so every change is traceable and repeatable. Alongside this, I'm exploring how **agentic AI** (RAG, LangGraph, MCP) can remove repetitive DevOps work and make engineers faster.

My goal is to grow into a cloud and platform engineer who understands both infrastructure and AI, and can build systems that are automated, secure and easy to operate.
